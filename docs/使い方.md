# 使い方

Claude Code の使用量を、画面に常時表示しておくための小さな常駐アプリ。

```
5h 35% 3:13  │  週 89% 7:03  │  Fable 0% 7:03
```

| 表示 | 意味 |
|---|---|
| `5h 35%` | 5 時間リミットを 35% 使った |
| `3:13` | そのリミットがリセットされるまで 3 時間 13 分 |
| `週 89%` | 週次リミットを 89% 使った |
| `Fable 0%` | モデル別（週次）の消費率。返ってきたモデルの分だけ並ぶ |

数値の色は **青（通常）→ 琥珀（警告）→ 赤（上限付近）**。
このしきい値はサーバーが返す値をそのまま使っているので、`claude.ai` の画面や
`/usage` の表示と食い違わない。

---

## 1. 初回セットアップ

### 手順

```powershell
# 1. ビルドする（publish\ClaudeUsageTray.exe が 1 個だけできる）
cd <このリポジトリ>
dotnet publish src\ClaudeUsageTray -c Release -o publish

# 2. 固定の場所へ配置して、自動起動に登録する
.\publish\ClaudeUsageTray.exe --install
```

`--install` は次の 3 つをまとめてやる。

1. `%LOCALAPPDATA%\ClaudeUsageTray\app\` へコピー
2. Windows の自動起動（HKCU の Run キー）に登録
3. コピーしたほうを起動

終わると「インストールしました」というダイアログが出る。以降は **Windows に
サインインすると自動で立ち上がる**。

> **なぜコピーが要るのか**
> 自動起動はレジストリに exe のフルパスを書く。`publish\` やダウンロード
> フォルダのままだと、ビルドし直したりフォルダを整理した時点で黙って壊れる。

### インストールできたか確かめる

ダイアログを閉じたあと、**画面のどこかにパネルが出ていれば成功**。

初回は **プライマリモニタの右下（タスクバーのすぐ上）** に出る。
最初は `Claude 使用量  取得中…` と表示され、数秒で数値に変わる。

見当たらない場合は PowerShell で確認する。

```powershell
# プロセスが動いているか
Get-Process ClaudeUsageTray

# パネルの実際の位置（マルチモニタだと別画面に出ていることがある）
Add-Type -AssemblyName System.Windows.Forms
[System.Windows.Forms.Screen]::AllScreens | Select-Object DeviceName, Bounds
```

> ⚠ **マルチモニタの人は特に注意。** 位置を記憶する仕組みなので、
> 一度動かすと次回からそのモニタに出る。「消えた」と思ったら
> まず他のモニタを見ること。

### 必要なもの

| | |
|---|---|
| OS | Windows 10 / 11 |
| ランタイム | **.NET Desktop Runtime 9** |
| 前提 | Claude Code にサインイン済みであること |

#### .NET Desktop Runtime が無いとき

起動しようとすると「このアプリケーションを実行するには .NET を
インストールする必要があります」というダイアログが出る。
表示されるリンクか、以下から **Desktop Runtime**（ASP.NET Core や
SDK ではない）を入れる。

```powershell
# 入っているか確認
dotnet --list-runtimes | Select-String "WindowsDesktop"
# -> Microsoft.WindowsDesktop.App 9.x.x があれば OK

# 未導入なら（winget が使える場合）
winget install Microsoft.DotNet.DesktopRuntime.9
```

> ⚠ **自動起動との組み合わせに注意。** ランタイムが入っていない状態で
> 自動起動が登録されていると、**サインイン時に何も起きない**（エラーも
> 出ないことがある）。動かなくなったらまずここを疑う。

## 2. 操作

パネルそのものが操作対象。トレイアイコンは無い。

| 操作 | 効果 |
|---|---|
| **ドラッグ** | 移動する。手を離した時点で位置を保存 |
| **右クリック** | メニューを開く |
| **Ctrl+Shift+U** | 移動モードの切り替え（後述） |

### メニューの中身

| 項目 | 説明 |
|---|---|
| 今すぐ更新 | 次の自動更新を待たずに取りに行く |
| 表示位置を動かす | 移動モードに入る。`Ctrl+Shift+U` と同じ |
| クリックを下へ透過する | 下記参照 |
| Windows 起動時に開始 | 自動起動の ON / OFF |
| ログフォルダを開く | 調子が悪いときはここを見る |
| 終了 | 常駐をやめる |

### クリック透過について

既定は **OFF**（＝パネルがクリックを受け取る）。そのぶんパネルの下にある
ボタンなどは押せなくなるが、掴んで動かせて右クリックメニューも出せる。

邪魔なときはメニューから **ON** にすると、クリックが下のウィンドウへ素通りする
ようになる。ただし **掴めなくなる** ので、動かしたいときは `Ctrl+Shift+U` で
移動モードに入る（赤い枠が出ている間はドラッグできる。もう一度押すと戻る）。

### 表示位置

マルチモニタでも大丈夫。位置は「どのモニタの、どのあたり」という形で覚えるので、
解像度を変えてもモニタを抜き差ししても画面外に消えない。

---

## 3. 更新の頻度

既定は **2 分に 1 回**。リセットまでの残り時間の表示だけは 1 秒ごとに更新される。

> **60 秒より短くはできない。** Claude Code 本体が同じ取得先を内部で 60 秒
> スロットルしているため、それより速く叩くのは行儀が悪く、レート制限に
> 当たるリスクもある。設定や引数で短い値を渡しても 60 秒に丸められる。

---

## 4. 表示が出ないとき

### まず確認すること

1. **別のモニタに居ないか。** 前回置いた位置を覚えているので、普段使わない
   モニタに残っていることがある
2. **全画面のアプリを開いていないか。** ゲームやプレゼン中は自動で引っ込む
3. タスクマネージャーに `ClaudeUsageTray.exe` が居るか

見失ったときは、いったん終了して設定ファイルを消すと既定位置（プライマリ
モニタの右下）に戻る。

```powershell
taskkill /f /im ClaudeUsageTray.exe
del "$env:LOCALAPPDATA\ClaudeUsageTray\settings.json"
& "$env:LOCALAPPDATA\ClaudeUsageTray\app\ClaudeUsageTray.exe"
```

### 数字の代わりに出るもの

| 表示 | 意味 | どうするか |
|---|---|---|
| `取得中…` | まだ 1 回も取れていない | 少し待つ |
| `Claude Code を起動してください` | 認証が切れた | Claude Code を起動する。自動で復帰する |
| `接続できません` | ネットワークか取得先の問題 | しばらく待つ |
| `N分前` | 値はあるが更新できていない | 同上 |

**認証が切れたときにこのアプリ側で何かする必要はない。** Claude Code を起動
すれば本体がトークンを更新し、こちらはそれに追従して自動で復帰する。

### ログ

```
%LOCALAPPDATA%\ClaudeUsageTray\logs\tray.log
```

取得した生のレスポンスは `%LOCALAPPDATA%\ClaudeUsageTray\cache\last-usage.json`
に残している。表示がおかしいときはこれを見ると原因が分かる。

## 5. やめるとき

```powershell
& "$env:LOCALAPPDATA\ClaudeUsageTray\app\ClaudeUsageTray.exe" --uninstall
```

自動起動の登録を解除して、配置したファイルを消す。

配置先の exe を自分で叩いているので、**フォルダの削除はダイアログを閉じた
数秒後**に行われる（動いている自分自身のフォルダは即座には消せないため）。

設定とログ（`%LOCALAPPDATA%\ClaudeUsageTray\`）は残る。完全に消すなら:

```powershell
Remove-Item -Recurse -Force "$env:LOCALAPPDATA\ClaudeUsageTray"
```

うまくいったかの確認:

```powershell
Get-Process ClaudeUsageTray -ErrorAction SilentlyContinue        # 何も出なければ停止済み
Get-ItemProperty "HKCU:\Software\Microsoft\Windows\CurrentVersion\Run" `
  -Name ClaudeUsageTray -ErrorAction SilentlyContinue            # 何も出なければ登録解除済み
```

自動起動だけ止めたいなら、パネルを右クリックして「Windows 起動時に開始」の
チェックを外すだけでよい。Windows の「設定 > アプリ > スタートアップ」から
切っても同じ。

---

## 6. 引数

| 引数 | 用途 |
|---|---|
| `--install` | 配置して自動起動に登録する |
| `--uninstall` | 登録を解除して配置したファイルを消す |
| `--startup` | 自動起動から呼ばれる印。初回取得を 15 秒遅らせる |
| `--interval <秒>` | 更新間隔。**60 未満は 60 に丸められる** |
| `--endpoint <URL>` | 取得先の差し替え。異常系を試すとき用 |

---

## 7. 保存される場所

| 何 | どこ |
|---|---|
| 本体 | `%LOCALAPPDATA%\ClaudeUsageTray\app\` |
| 設定（位置・透過など） | `%LOCALAPPDATA%\ClaudeUsageTray\settings.json` |
| ログ | `%LOCALAPPDATA%\ClaudeUsageTray\logs\` |
| 取得結果のキャッシュ | `%LOCALAPPDATA%\ClaudeUsageTray\cache\` |

`~/.claude`（Claude Code 本体のフォルダ）には**何も書き込まない**。読むだけ。
